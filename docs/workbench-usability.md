# 工作台测试与易用性评估

评估对象：`scripts/workbench.py`（1183 行）、`scripts/workbench_logic.py`（299 行）。
评估时间：2026-11-14 · 环境：Windows + Python 3.13.9 + Tk 8.6，窗口默认 1180×760。

## 1. 方法与复现

| 手段 | 命令 | 规模 |
|---|---|---|
| 自动化 UI 测试 | `python -m unittest tests.test_workbench_ui -v` | 16 个用例，真实 Tk 实例，不进入 mainloop |
| 纯逻辑测试 | `python -m unittest tests.test_workbench_logic -v` | 35 个用例 |
| 全套回归 | `python -m unittest discover -s tests` | 80 个用例 |
| 客观指标采集 | `python tools/measure_workbench_ui.py` | 控件尺寸、文本截断、快捷键、弹窗统计 |

UI 测试整组在无显示环境自动跳过（用子进程探测 Tk，避免污染当前进程）。测试共用一个 Tk 根：多解释器会让 `tkinter.Variable.__del__` 抛
`main thread is not in main loop`，这是 Tkinter 测试的已知坑，已在测试文件顶部注释说明。

## 6. 待改进项（按严重度）

**P1-1 左栏路径截断**：实测典型科研路径 444px > 左栏 240px，长路径会被裁切。
建议：左栏改成可拖拽宽度，或给列表项加 tooltip（现在靠悬停写状态栏，视线要来回移动）。

**P1-2 弹窗偏多**：33 处 messagebox，其中 14 处 showerror。
建议：把「生成前检查」「覆盖确认」并入非模态提示条 + 「仍要继续」按钮；错误统一进结果区，仅致命错误弹窗。

**P1-3 快捷键覆盖不全**：校验、单页重建、页签切换、打开输出、刷新历史无快捷键。
建议：Ctrl+E 校验、Ctrl+Shift+Enter 单页重建、Ctrl+1..5 跳页签、Ctrl+Shift+O 打开输出目录。

**P1-4「放弃等待」语义易误解**：后台线程仍会写完文件。
建议：按钮文案改「仅停止等待」，并在结果区用醒目一行说明；长期方案是给引擎加取消点（见 P2-1）。

**P2-1 生成无法真取消**：`run_generate` 没有取消钩子。
建议：在逐页 `draw` 之间检查取消标志，全量与 `--slide` 都支持；工作台把标志透传给引擎。

**P2-2 预览缩放后无平移**：放大到 150% 后可能超出可视区。
建议：预览区加滚动条或按住拖动平移。

**P2-3 模板管理不完整**：只能新建/覆盖，不能复制、重命名、删除、设唯一默认。
建议：模板列表加右键菜单（复制/重命名/删除/设为默认），保存时收敛 `default: true` 唯一性。

**P2-4 无跨文件撤销**：文本撤销只在当前会话内有效。
建议：保存时写同名 `.bak`，或在历史页提供「回到上次保存」。

**P2-5 适配性**：无深色主题跟随、无 i18n、字号不可调。
建议：ttk 主题跟随系统；文案抽到字典；提供「界面缩放」。

**P3-1 空状态缺引导**：未打开 brief 时大纲/历史为空白。
建议：空列表处显示「双击左栏打开 brief」「先设置历史目录」等占位文案。

**P3-2 大纲只能按钮排序**：不支持拖拽与多选。
建议：启用 Treeview 拖拽排序，与人机效率优化一起做。

## 7. 本轮已修复（对照上一版评估）

| 原问题 | 现状 |
|---|---|
| 未保存编辑直接丢 | 标题 ● + 关闭/切换/新建前确认 + Ctrl+S |

| 生成阻塞界面 | 后台线程 + 进度条 + 放弃等待 |

## 8. 建议排期

1. **P1-2 + P1-3**（一轮，纯 UI）：减少弹窗、补齐快捷键。
2. **P2-1**（引擎改动 + 测试）：真正可取消的生成，同时把「放弃等待」改为「取消生成」。
3. **P1-1 + P2-2**（布局）：左栏可调宽、预览可平移。
4. **P2-3 + P3-1 + P3-2**（模板右键菜单、空状态、拖拽排序）。
5. **P2-4 / P2-5**（工程性打磨，随版本节奏）。

## 附：结论

- 功能完整性：10 类版式 + 模板 + 历史 + 大纲 + 后台生成，主流程闭环。
- 可用性短板集中在弹窗与快捷键这类交互细节，以及引擎不具备取消能力这一处结构限制；没有发现阻断性缺陷。
- 自动化覆盖已从「逻辑可测」扩展到「真实 Tk 行为可测」，共 80 个用例，后续 UI 重构有回归网。
